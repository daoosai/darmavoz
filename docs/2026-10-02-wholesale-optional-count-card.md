# Необязательное количество машин и общая карточка оптовой заявки
Контур: develop, /opt/darmavoz_test, test.darmavoz.ru/app.
Обе задачи объединены в один коммит и push по просьбе пользователя.

Поле API/БД называется vehicle_count (не vehicles_count). WholesaleInput,
который используется для POST и PUT, допускает None по умолчанию. Отсутствующее
поле, null, пустая строка и 0 нормализуются в None; заданное число — целое 1..100000.
Отрицательные/дробные/слишком большие значения отклоняются. WholesaleOut тоже nullable.
Модель vehicle_count nullable=True; миграция s24_wholesale_optional_vehicles
после s24_wholesale_moderation_cycle снимает NOT NULL без изменения старых чисел.
Существующий CHECK допускает NULL по правилам PostgreSQL и сохраняет >0
для заданного числа. Downgrade запрещён: нельзя выдумывать число для пустых записей.

Форма: «Количество машин (необязательно)», required убран, подсказка
«Заполните, если вам требуется конкретное количество техники на объекте».
Пустое поле отправляет null, редактирование null показывает пустой input.

WholesaleRequestCard — общий компонент frontend/src/WholesaleRequestCard.tsx
для предпросмотра формы, списка/деталей модерации админа, списка/деталей водителя
и «Мои заявки». Название материала и объём крупно в шапке.
Маршрут, сроки, количество машин — отдельные строки с lucide иконками.
Ставка выделена sky-фоном; комментарий и контакты отделены. Телефон с маской,
звонок/копирование доступны в опубликованных карточках; preview не запускает звонок.
При null/0 строка машин отсутствует. Одинаковые даты отображаются один раз,
разные даты — читаемый русский диапазон без сдвига дня из-за часового пояса.
Причина отклонения остаётся красной; статус, избранное, редактирование и кнопки
модерации сохранены. Исправления rejected снова отправляются pending.

Файлы: app/models/commerce.py, app/schemas/commerce.py, миграция,
frontend/src/WholesaleRequestCard.tsx, WholesaleScreen.tsx.
Проверки API: omitted/null/0 -> pending, изменение 7 -> очищение,
одобрение и чтение водителем с null, недопустимые числа -> 422.
