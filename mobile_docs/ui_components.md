# UI Компоненты и Верстка

## Структура экрана Home (Каталог)

Экран `/home` (файл `mobile/lib/presentation/home/home_screen.dart`) сверстан для адаптации под доставку сыпучих материалов. Использована структура на базе `SafeArea` и `Column`, что позволяет закрепить верхние элементы управления и дать сетке товаров возможность скроллиться независимо.

**Дерево виджетов экрана Home:**
- `Scaffold`
  - `SafeArea`
    - `Column`
      - **Верхний блок:** `Padding` -> `InkWell` -> `Container` (Синяя плашка-кнопка "Укажите адрес доставки" с иконкой локации `Icon(Icons.location_on_outlined)` и текстом).
      - **Поиск:** `Padding` -> `TextField` (Строка поиска с иконкой лупы). При вводе текста обновляется локальное состояние `_searchQuery`.
      - **Категории:** `SizedBox` -> `ListView.separated` (Горизонтально скроллящийся список, использующий `ChoiceChip` для фильтрации: 'Все', 'Песок', 'Щебень', 'Грунт', 'Керамзит'). При выборе обновляется локальное состояние `_selectedCategory`.
      - **Сетка товаров:** `Expanded` -> `FutureBuilder` -> `GridView.builder` (Сетка в 2 колонки).
        - Перед передачей в `GridView`, список товаров из API фильтруется на клиенте: сначала по `_selectedCategory`, затем по совпадению названия с `_searchQuery`.
        - `ProductCardWidget` (Умная карточка товара)

## Переиспользуемые виджеты

### ProductCardWidget
**Расположение:** `mobile/lib/presentation/core/widgets/product_card_widget.dart`

Это изолированный и переиспользуемый компонент карточки товара (`StatefulWidget`), который можно вызывать на других экранах (например, на экране поиска или в акциях).

**Особенности реализации:**
- **Контейнер карточки:** Белый фон, скругленные углы (`BorderRadius.circular(16)`) и легкая тень (`BoxShadow`), как в визуальном референсе.
- **Изображение:** Пока используется серый `Container` с `Icon(Icons.image)` в качестве плейсхолдера (`Expanded`, чтобы занимать оставшееся верхнее пространство). При наличии загружается картинка через `Image.network`.
- **Данные:** Принимает объект `Product` (включающий название, цену, единицу измерения и т.д.).
- **Контроллер объема:** Интегрирован счетчик количества (тип `double`, так как сыпучие материалы заказывают в дробных долях, например кубах или тоннах, минимальный шаг 1.0). Реализован через `Row` с кнопками `[-]` и `[+]`. Состояние объема инкапсулировано внутри виджета.
- **Кнопка "В корзину":** Добавлена яркая кнопка с динамическим подсчетом стоимости (`_quantity * product.price`). Цена мгновенно пересчитывается при изменении количества.

## Структура экрана Profile (Профиль)

Экран `/profile` (файл `mobile/lib/presentation/profile/profile_screen.dart`) переработан в "гостевой режим" и содержит четыре основные точки входа:

**Особенности реализации:**
- **Шапка гостя:** Верхний блок с серым аватаром-заглушкой (`CircleAvatar`) и текстовой кнопкой «Вход / регистрация» в качестве призыва к действию.
- **Список действий:** Реализован через `ListView` с использованием `ListTile` и разделителями `Divider`. Содержит пункты "Обратная связь", "Поделиться приложением" и "О компании".
- **Версия проекта:** В самом низу экрана отображается текущая версия приложения, которая автоматически берется с платформы через плагин `package_info_plus`.
