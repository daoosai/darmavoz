# Реестр заказов администратора и полное удаление

GET /admin/orders показывает активные/архивные заказы с фильтрами.
AdminOrdersListScreen использует DELETE /admin/orders/{id}/hard после
явного подтверждения полного удаления. Доступ — только admin.
Обычный DELETE /admin/orders/{id} и /orders/{id} сохраняет мягкое архивирование.

Hard delete реализован в app/services/order_deletion.py:
блокировка заказа → разрыв current_offer/source_dialogue циклов →
отвязка диалогов → события/возвраты/чеки платежей → платежи →
подтверждённые стоимости → order inbox/outbox → история подбора,
события, предложения, позиции → сам заказ. Прямые FK сверены с test PostgreSQL.
OrderTrip отдельно в текущей схеме нет: сведения о рейсах являются полями Order.
PushDelivery/UserNotification связываются через payload.order_id, очищаются
точным сопоставлением. Разговоры, клиенты, материалы и другие заказы сохраняются.
Водитель освобождается, если не осталось активного назначения; смена учитывается.

Все операции выполняются одной транзакцией. IntegrityError откатывает всё,
логирует order_id/actor_id и имя ограничения, возвращает понятный HTTP 409.
Soft archive и его история не менялись. Каскады ORM не расширялись глобально:
финансовые записи удаляются только при явном admin hard delete. Миграций нет.
Удаление локальных платежных записей не вызывает возврат/списание у провайдера.

Тесты: tests/test_admin_order_hard_delete.py (полный граф, успешный/ожидающий
платёж, архив, другая запись, driver shift/assignments, rollback, admin permissions,
повторный DELETE), frontend/tests/e2e/admin-order-hard-delete.spec.ts (DELETE hard,
успех/конфликт/отмена подтверждения); две существующие проверки архива.
Все проверки данного пути включены в deploy-test.
Отчёт: ../2026-10-14-admin-order-hard-delete.md.

## 14.10.2026 — новая политика финансовой истории

Предыдущее описание очистки платежных зависимостей при Hard Delete больше не применяется: при любой Payment полное удаление теперь запрещено (409), финансовые записи сохраняются. В реестре вместо удаления доступен архив. Заказы только с PaymentQuote можно удалить. Архив до выезда водителя ставит полный остаток в очередь возвратов; после выезда возврат определяется вручную. См. [refunds.md](refunds.md).
