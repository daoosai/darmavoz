# Мобильное приложение Дармавоз.рф (Flutter)

**Sprint 9 успешно завершён.**

## Архитектура и структура проекта
Проект организован с использованием единой кодовой базы, которая разделена на два отдельных приложения (клиентское и водительское) с помощью **Flavors**.

* **Два Entrypoints:**
  * `lib/main_client.dart` — точка входа для клиентского приложения.
  * `lib/main_driver.dart` — точка входа для водительского приложения.

* **Сборка через Flavors:**
  * Для клиента используется flavor `client` (Application ID: `ru.darmavoz.client`).
  * Для водителя используется flavor `driver` (Application ID: `ru.darmavoz.driver`).
  * Сборка и подпись релизных APK настроены с использованием Release Keystore. CI/CD пайплайн (GitHub Actions) автоматически собирает оба артефакта.

* **Сетевой слой и Роутинг:**
  * Реализован базовый сетевой слой с использованием **Dio** (в `ApiService`).
  * Роутинг построен на **go_router** (с использованием `StatefulShellRoute` для сохранения состояния вкладок), что полностью соответствует описанию в `architecture.md`.
  * Реализована проверка обновлений через `package_info_plus`.
