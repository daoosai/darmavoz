# Сохранение адресов клиента — 11.10.2026

Контур кода и доставки: develop / test.darmavoz.ru. Production проверен контрольным запросом; код production не изменяется этой задачей.

## Расследование
Проверены payload, схемы Pydantic, endpoints и JWT. Поля full_address, lat, lon, comment и city_id совпадают; обязательных street/house нет. Reverse geocoding не меняет контракт. Авторизованный контрольный клиент сохранил через тестовый браузер реальную подсказку 2GIS с HTTP 201.

Конкретный адрес пользователя: Патрушева, Садовая улица, 3а, координаты 57.091586/65.533642. Подсказка содержит полноценный адрес и координаты. Контрольный запрос по внешнему production HTTPS вернул 201. Временный production-клиент и его адрес удалены после проверки; реальные клиенты не изменялись. Пользователь затем подтвердил успешное сохранение с ПК и телефона до доставки исправлений. Причина исходного временного отказа без его HTTP-ответа не установлена; приписывать его 422 или истекшей сессии оснований нет.

Подтверждены две ошибки интерфейса: общий зелёный style Toaster применялся и к toast.error(), а сохранение скрывало статус/тело любого неуспешного HTTP-ответа за текстом «Не удалось сохранить адрес».

## Исправления
Раздельные стили success/error. Неуспешный ответ API разбирается с сохранением введённых данных. Для 401 предусмотрен повторный вход через штатную клиентскую форму с сохранением адреса, координат и комментария; после входа адрес сохраняется повторной кнопкой, без обхода авторизации. Backend и контракт не менялись. Номера версии/сборки, .env не менялись.

## Проверки и доставка
npm run lint и npm run build успешны. Первые 4 Playwright-теста прошли, включая сохранение после повторного входа; добавлена отдельная регрессия 422. Окончательные проверки размеров экранов, commit/push и фактической доставки записываются после завершения.

Изменения относятся к frontend. Для веб-сайта нужен деплой статики, выпуск новой версии мобильного приложения для пользователей веба не требуется. Для получения этих изменений в установленном мобильном приложении потребуется обновление его frontend/сборки.
