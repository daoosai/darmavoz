# Интерфейс оптовых заявок для водителя — 02.10.2026

Контур: develop, /opt/darmavoz_test, test.darmavoz.ru/app.

WholesaleScreen проверяет роль из useAuthStore. Только supplier получает
баннер «Найдите перевозчиков», создание, «Мои заявки» и редактирование.
Для driver остаются «Все» и «Избранное» с существующими поиском/фильтрами.
В пустой ленте водитель не получает предложение создать свою заявку.
Переход из старого уведомления у водителя выбирает общую ленту, а не скрытую
вкладку mine; конкретная карточка продолжает открываться.
Баннер удаляется из DOM, поэтому вкладки сразу следуют после header и
обычных отступов CommerceShell, без пустого блока.

Поставщик сохраняет три вкладки, создание, предпросмотр/черновики и модерацию.
Backend/RBAC не менялись: задача ограничена адаптацией интерфейса.

Проверки: npm run lint, npm run build; существующие Sprint24 E2E адаптированы
для ролей driver/supplier, проверяют навигацию на 320/1440, отсутствие создания
у водителя и доступность избранного, сохранность предпросмотра и черновиков.
Фактические результаты CI/deploy, commit и внешней проверки записываются
после push в docs/reports/wholesale-driver-view-live.json на ноде.
Production, .env, версии приложения не менялись.
