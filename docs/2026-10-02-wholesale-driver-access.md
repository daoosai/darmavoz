# Допуск водителей к оптовой бирже — 02.10.2026

Контур: develop, /opt/darmavoz_test, test.darmavoz.ru/app.

Правило: driver допускается только при наличии активного Driver с
moderation_status=approved и привязанной активной Vehicle с
moderation_status=approved. В проекте используется approved, отдельного
модерационного состояния active в enum нет. Supplier и staff сохраняют доступ.

Общая зависимость board_user проверяет допуск на каждом запросе. GET списка,
access, деталей, истории и остальные операции раздела возвращают 403 для
непроверенного водителя: скрыть UI недостаточно, прямой API тоже закрыт.
Нет профиля/машины, incomplete/pending_moderation/rejected/suspended,
неактивная машина или водитель не допускаются. Блокировка аккаунта сохраняет 401.

WholesaleScreen сначала проверяет /wholesale-requests/access для driver;
до допуска не запрашивает ленту/детали и не показывает табы/фильтры/карточки.
403 от access или последующих запросов отображает Lock + «Доступ закрыт» +
текст о завершении оформления и модерации. Header и нижняя навигация остаются.
Нет глобального красного toast/alert для этого 403; временная сетевая ошибка
проверки закрывает контент и даёт спокойный текст с кнопкой повтора.
commerceApi сохраняет HTTP status в объекте ошибки.
Для supplier дополнительный access-запрос не вводится.

Проверки: npm run lint/build; pytest Sprint24 в одноразовой БД (63 passed).
API-матрица проверяет состояние профиля и машины, отсутствие/неактивность
машины, отсутствие профиля, все виды ленты и прямые детали/историю.
E2E покрывает первоначальный 403 и 403 после успешного access, отсутствие
списка/фильтров/toast, сохранность supplier/approved-driver и модерации.
Итог CI/deploy и внешней проверки: docs/reports/wholesale-driver-access-live.json
на ноде, формируется после push без второго коммита документации.
Миграции, версии/.env и production не меняются.
