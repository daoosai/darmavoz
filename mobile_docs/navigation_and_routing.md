# Архитектура интерфейса: Навигация и Роутинг

## 1. Выбранный паттерн роутинга
Для навигации в приложении используется пакет `go_router`. В качестве стартового экрана выступает `RoleSelectionScreen`, обеспечивающий разделение клиентского и водительского контуров.

Для реализации `BottomNavigationBar` (нижней панели вкладок клиента) с сохранением состояния каждого экрана при переключении применен паттерн **StatefulShellRoute**.

**Зарегистрированные пути:**
- `/role-selection` — Стартовый экран выбора роли
- `/driver-stub` — Заглушка кабинета водителя
- `/home` — Главная / Каталог (Клиент)
- `/orders` — Заказы (Клиент)
- `/cart` — Корзина (Клиент)
- `/promos` — Акции (Клиент)
- `/profile` — Профиль (Клиент)

Конфигурация роутера находится в файле `mobile/lib/router/app_router.dart`. При переходе между вкладками метод `goBranch` позволяет не терять набранный текст или позицию скролла внутри конкретного экрана.

## 2. Цветовая палитра (ThemeData)
В `mobile/lib/theme/app_theme.dart` настроена базовая `Material` тема:
- **Основной цвет (Primary):** Глубокий синий `#0D47A1` (используется для AppBar, активных элементов и выделенной вкладки BottomNavigationBar).
- **Цвет фона (Background):** Светло-серый `#F5F5F5` (создает контраст для карточек товаров и списков).
- **Цвет неактивных элементов:** Стандартный серый (для невыделенных вкладок).

## 3. Структура папок
Код мобильного приложения изолирован в директории `mobile/`.

```text
mobile/
├── lib/
│   ├── main_client.dart               # Точка входа для клиентского приложения
│   ├── main_driver.dart               # Точка входа для приложения водителя
│   ├── theme/
│   │   └── app_theme.dart             # Настройки цветов и базовой темы
│   ├── router/
│   │   └── app_router.dart            # Настройки go_router и роуты
│   └── presentation/                  # UI слой приложения
│       ├── role_selection/
│       │   └── role_selection_screen.dart # Стартовый экран выбора роли
│       ├── driver_stub/
│       │   └── driver_stub_screen.dart    # Заглушка кабинета водителя
│       ├── core/
│       │   └── main_scaffold.dart     # Главная обертка с BottomNavigationBar
│       ├── home/
│       │   └── home_screen.dart       # Экран "Главная"
│       ├── orders/
│       │   └── orders_screen.dart     # Экран "Заказы"
│       ├── cart/
│       │   └── cart_screen.dart       # Экран "Корзина"
│       ├── promos/
│       │   └── promos_screen.dart     # Экран "Акции"
│       └── profile/
│           └── profile_screen.dart    # Экран "Профиль"
├── pubspec.yaml                       # Зависимости (включая go_router)
└── ...
```
