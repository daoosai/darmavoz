# Полный цикл модерации оптовых заявок
Контур: develop, /opt/darmavoz_test, test.darmavoz.ru.

Снятие whitelist оформлено отдельно коммитом f9675b73.
Активные driver/supplier создают и просматривают заявки без отдельного допуска.
Клиенты, спецтехника и вода/септики не имеют доступа; заблокированные аккаунты отклоняются.

Модель WholesaleRequest: status pending/approved/rejected/archived,
reject_reason nullable. Создание сразу pending. Любое сохранение исправлений
неархивной заявки возвращает её в pending и очищает reject_reason.
Общая лента показывает только approved с действующими сроками.
Решение approve/reject допустимо только для pending; reject требует непустую причину.
Повтор того же решения идемпотентен. Архивные заявки нельзя редактировать.

Миграция s24_wholesale_moderation_cycle после s25_driver_cities_push:
переименовывает moderation_reason в reject_reason, сохраняет заявки/историю,
переводит draft/pending_moderation -> pending, published -> approved,
hidden/closed -> archived; добавляет ограничения статуса и причины.
Старые published не становятся новыми публикациями — их статус только переименован.
Старые draft попадают в очередь модерации. История и ссылки сохраняются.

Уведомления: решение, WholesaleEvent, PushDelivery и UserNotification сохраняются
в одной транзакции. Используется notification_outbox Спринта 25.
Дедупликация по event_id; просроченный по версии события PUSH отменяется.
Для автора-водителя используется Driver.fcm_token, для поставщика User.fcm_token.
В PUSH включена причина (до 500 символов для размера FCM); полная причина хранится
в заявке и видна в кабинете. PUSH/центр уведомлений открывает конкретную заявку.
Доставка FCM на физические Android/iOS устройства требует действующего токена
и конфигурации Firebase; отсутствие устройства не блокирует решение модератора.

Админ: раздел «Модерация» -> карточка «Оптовые заявки» -> очередь pending.
Карточки открывают детали, «Одобрить», «Отклонить», «В архив».
Причина вводится общей components/admin/ReasonModal.tsx, пустой ввод запрещён.
Поставщик: «Опт» -> «Мои», цветные бейджи, красная причина,
кнопка «Редактировать» с заполненной формой. Кнопка «Сохранить» сразу отправляет на модерацию; предпросмотр необязателен.
«Мои заявки» показывает статус «Отклонено». В разделе есть штатный колокольчик
с открытием конкретной заявки. Черновики и отдельное подтверждение допуска убраны.
