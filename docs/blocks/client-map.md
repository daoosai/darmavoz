# Публичная клиентская карта

Назначение: показать гостю или авторизованному клиенту публичные карьеры/накопители рядом с геопозицией без ввода адреса. API GET /api/v1/catalog/pickup-points/global: при lat/lon радиус 50 км, radius_km до 200 км; при отсутствии координат сохраняется city_id. Публичность определяется CRM-фильтром; скрытые, отказанные, необработанные записи не выдаются. Зелёный маркер: activated/agreed, активная точка, активное предложение с положительной ценой либо бесплатный материал; другие публичные точки серые.

GlobalMapScreen получает геопозицию, при отказе использует центр выбранного города, загружает API без авторизации, вмещает пользователя и точки в начальный обзор 2ГИС. Геопозиция не переключает город корзины. Заказы остаются с прежней авторизацией и проверками города.

Файлы: app/api/pickup_points.py, frontend/src/GlobalMapScreen.tsx. Проверки: tests/test_global_map_location.py, frontend/tests/e2e/global-map-location.spec.ts; отчёт ../2026-10-12-client-map-geolocation.md. Новых миграций нет. Область загрузки — радиус от геопозиции, а не динамическое обновление при каждом перемещении камеры. Старые мобильные сборки без lat/lon сохраняют прежнее поведение.

Маркеры имеют явный zIndex SDK: серые 1, зелёные 2, пользователь 3, выбранная точка 4. Это сохраняет зелёные точки поверх соседних серых на обзорном масштабе.

Развёрнуто и проверено в тестовом и боевом контурах 12.10.2026. Реальные гостевые проверки ПК/мобильного браузера подтверждают геозапрос, зелёные/серые точки и отсутствие перекрытия зелёных маркеров. JSON и результаты доставки — в отчёте задачи.

12.10.2026 develop: selectedAddressCoordinates приоритетнее GPS, MapOptions и начальный setCenter используют адрес. Для адреса без координат выполняется геокодирование; GPS используется только без выбранного адреса. Кнопка центрирования повторяет приоритет. Отчёт: ../2026-10-12-suburbs-cart-map.md.

Изменения 12.10.2026 развернуты только в тестовом контуре (runtime 48a4cd0a), CI success. Живой расчёт с временным пригородным city_id подтвердил тот же карьер/цену, что для Тюмени; временная запись удалена. Реальная 2ГИС на ПК/мобильном браузере подтвердила selectedAddress как центр и 0 GPS вызовов. Доказательства в отчёте suburbs-cart-map.

## 14.10.2026 — ошибки загрузки SDK и восстановление карты

Общий load2GisMapSdk повторно загружает SDK, если исходный script из HTML
не создал window.mapgl. Успешная загрузка переиспользуется; rejected promise
сбрасывается, error/timeout очищают обработчики и не оставляют карту
заблокированной до перезагрузки страницы. Совместные запросы используют
один promise. Проверка WebGL использует SDK isSupported; старый fallback
освобождает пробный GPU-контекст.

GlobalMapScreen различает отсутствие WebGL, загрузку SDK, ошибку создания
карты и отсутствие ключа. Кнопка «Повторить загрузку» повторяет инициализацию
без перезагрузки страницы. Контейнер карты сохраняется при ошибке.
Общий fallback больше не объявляет любую ошибку отсутствием WebGL и не
предлагает несуществующий на данном экране режим списка.

Файлы: frontend/src/components/MapWebGLFallback.tsx, GlobalMapScreen.tsx.
Регрессии: frontend/tests/e2e/map-recovery.spec.ts (обрыв SDK → восстановление,
WebGL, constructor error), global-map-location.spec.ts (геолокация/адрес).
Оба spec включены в test deploy. Backend, ключи и версии не менялись.
Ограничение: реальная недоступность WebGL не исправляется повторной загрузкой;
растровая карта в этой задаче не внедрялась.
Отчёт: ../2026-10-14-map-recovery.md.
