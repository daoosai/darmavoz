# Спринт 22: города и калькулятор

Города создаются и публикуются в административном профиле. Каталоги и карты клиента используют выбранный город; корзины сохраняются раздельно. Запрос без `city_id` обращается к записи с кодом `tyumen`, независимо от административного города по умолчанию. Явно указанный недоступный город возвращает ошибку.

Города исполнителя редактируются в его профиле. Администратор может изменять привязки поставщика и водителя. Точка имеет один город обслуживания; координаты могут находиться за его пределами. Город заказа сохраняется отдельно и используется автоматическим и ручным подбором водителей. Удаление города не предусмотрено.

Калькулятор доступен на главном экране и из карточки материала. Справочник `/catalog/calculator/` не содержит цен. Расчёт использует точную десятичную арифметику для количества загрузок; кубатура машины выбирается явно. Плотность изначально не заполнена, её можно указать в администрировании материала либо вручную. Переход к поставщику сохраняет размеры и потребность, выбранная фактическая машина обновляет число загрузок. В корзину автоматически ничего не добавляется; оформление остаётся на одну машину.

## Перенос и выпуск

Миграция `s22_cities_calculator` объединяет две прежние вершины Alembic, добавляет nullable-привязки для старых записей и создаёт Тюмень. Миграция не удаляет существующие данные. Автоматический downgrade намеренно запрещён.

Для тестового контура пользователь подтвердил принадлежность всех существующих данных Тюмени. Workflow применяет это решение один раз командой `python -m scripts.city_backfill --assign-all-existing-city-code tyumen --apply`; факт выполнения хранится в городе. Конфликты прерывают выкладку без фиксации переноса. Тестовый бэкенд кратко останавливается на время миграции и переноса, затем пересоздаётся из нового образа. БД и хранилище не удаляются.

Это подтверждение относится только к тестовому контуру. Для другой базы сначала выполнить `python -m scripts.city_backfill` без `--apply`, проверить спорные записи и передать согласованный JSON через `--decisions`. Формат: `{ "quarries": { "UUID объекта": "код города" } }`. Исторические записи с неизвестным городом не дают права подбирать водителей без ограничения города.

CI запускает TypeScript-проверку, сборку фронтенда, тесты калькулятора и проверки городов на отдельном PostgreSQL. Локальные тесты по просьбе пользователя не запускаются. Выпуск проверяется по `alembic current`, единственной вершине `alembic heads`, ревизии образа и `/health`; сборки APK и iOS выполняются существующими workflow.
