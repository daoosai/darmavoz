# Авторизация
Контур: develop / test.darmavoz.ru.

POST /api/v1/auth/login принимает OAuth2 form username/password без телефонного Regex.
Сначала ищется буквальный username, затем нормализованные варианты телефона в users.username
и drivers.phone (в модели User отдельного phone нет). Неоднозначный телефон отклоняется.
Фронтенд передаёт логин с trim, сохраняя дефисы в именах сотрудников.
Пароли всех ролей проверяются обычным bcrypt. Удалённые/заблокированные профили отклоняются.

Админ получает JWT сразу. Водитель после пароля получает sms_sent;
POST /api/v1/driver/auth/verify-login проверяет OTP и привязку к тому же user_id, выдаёт JWT.
Google Play исключение относится только к OTP и не обходит пароль.

При старте app/db/seed.py создаёт отсутствующего администратора из конфигурации,
но больше не переписывает пароль существующего аккаунта.
Смена пароля должна быть явной операцией; изменение ADMIN_PASSWORD не сбрасывает существующий пароль.

Файлы: app/api/auth.py, app/security/auth.py, app/db/seed.py, frontend/src/LoginScreen.tsx.
Регрессии: tests/test_auth_hotfix.py, tests/test_driver_auth_otp.py.
