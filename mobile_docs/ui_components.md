# UI Компоненты и Верстка

## Структура экрана Home (Каталог)

Экран `/home` (файл `mobile/lib/presentation/home/home_screen.dart`) сверстан для адаптации под доставку сыпучих материалов. Использована структура на базе `SafeArea` и `Column`, что позволяет закрепить верхние элементы управления и дать сетке товаров возможность скроллиться независимо.

**Дерево виджетов экрана Home:**
- `Scaffold`
  - `SafeArea`
    - `Column`
      - **Верхний блок:** `Padding` -> `InkWell` -> `Container` (Синяя плашка-кнопка "Укажите адрес доставки" с иконкой локации `Icon(Icons.location_on_outlined)` и текстом).
      - **Категории:** `SizedBox` -> `ListView.separated` (Горизонтально скроллящийся список, использующий `ChoiceChip` для категорий 'Песок', 'Щебень', 'Грунт', 'Керамзит').
      - **Сетка товаров:** `Expanded` -> `GridView.builder` (Сетка в 2 колонки через `SliverGridDelegateWithFixedCrossAxisCount`).
        - `ProductCardWidget` (Карточка товара)

## Переиспользуемые виджеты

### ProductCardWidget
**Расположение:** `mobile/lib/presentation/core/widgets/product_card_widget.dart`

Это изолированный и переиспользуемый компонент карточки товара (`StatefulWidget`), который можно вызывать на других экранах (например, на экране поиска или в акциях).

**Особенности реализации:**
- **Контейнер карточки:** Белый фон, скругленные углы (`BorderRadius.circular(16)`) и легкая тень (`BoxShadow`), как в визуальном референсе.
- **Изображение:** Пока используется серый `Container` с `Icon(Icons.image)` в качестве плейсхолдера (`Expanded`, чтобы занимать оставшееся верхнее пространство).
- **Данные:** Принимает `title` (название) и `price` (цена) в качестве входных параметров.
- **Контроллер объема:** Вместо стандартной кнопки "В корзину", встроен счетчик кубов/тонн. Он реализован через `Row` с кнопками `IconButton(Icons.remove)` `[-]` и `IconButton(Icons.add)` `[+]`, а между ними — текстовое поле с текущим объемом (по умолчанию `1 м³`). Состояние объема инкапсулировано внутри виджета через `setState`.
