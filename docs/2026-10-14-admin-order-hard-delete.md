но начиная с driver_accepted («Водитель подтвердил заказ») сервер возвращает
409 ORDER_ALREADY_ACCEPTED; UI также не показывает отмену. Далее выезд,
погрузка, доставка/завершение запрещены. Оплата отдельно не является порогом.

а не driver_accepted. Кнопка «Выехать на карьер» сразу переводит его в
heading_to_pickup («Выехал на загрузку»), поэтому обычный пользовательский
порог — выезд. Если driver_accepted задан через штатный API, блокировка
начинается уже на нём. Принятие предложения само по себе при сохраняющемся
driver_assigned ещё не блокирует отмену.
