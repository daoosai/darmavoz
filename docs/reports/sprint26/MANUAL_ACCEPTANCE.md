Тест: https://test.darmavoz.ru/app. Code release `c3a8a29431fc247417b593fa6c34a391d5a7ca50`, version3.3.3/code391. Актуальные SHA/hash APK и фактический deploy — в [отчёте артефакта](android-artifact.json) и [SPRINT_26.md](../../SPRINT_26.md).


APK: [immutable тестовая сборка](https://test.darmavoz.ru/static/darmavoz-test-c3a8a29431fc247417b593fa6c34a391d5a7ca50.apk), SHA256 `a1c571b65ee957bae23aa4c262c51f29759db6f29e83e584b9f6d8007402c0d6`.

QA admin/logist/supplier/equipment_owner/water_septic_partner имеют обычный password login (HTTP200 проверен). Данные входа хранятся приватно на ноде в `/opt/darmavoz_test_backups/sprint26/qa-auth.json`0600, в отчётах паролей нет. На форме входа сотрудника допускается QA логин вместо телефона. Driver требует пароль **и SMS**; его выданный тестовый JWT не заменяет обычный вход. Для проверки driver/client используйте телефон, контролируемый QA; номер клиента/водителя в реальном контуре не подменять. Физический SMS/PUSH пока не подтверждены. [Проверка QA входа](qa-manual-login.json).

Использовать выделенные QA-профили нужных ролей и новые QA-заказы/точки. Автоматические тестовые credentials находятся приватно на ноде, в отчёты не включены. Не использовать настоящие платёжные инструменты: на форме ЮKassa должна быть надпись «Это тестовый платёж»; тестовый кошелёк ЮMoney работает без реального кошелька.

1. **Профиль и карта.** Войти водителем без доступа: видны уведомление о подписке, карта материалов/воды/септиков и профиль. На телефоне и планшете проверить портрет/альбом, прокрутку, длинные названия, нижнюю навигацию, safe-area, открытие/закрытие клавиатуры.
2. **Trial и машины.** В профиле открыть «Подписки», активировать14дней своей категории. Повтор не меняет дату окончания. Для driver/carrier срок общий; машина с использованным trial требует оплату/проверку администратора. Администратор проверяет историю номера и предоставляет отдельный срок с причиной, не стирая историю.
3. **Карта и контакты.** На отдельной QA-точке без доступа телефон скрыт, точка серая, новый заказ недоступен. После trial/подписки телефон/заказы доступны. Проверить quarry/manual accumulator; серый маркер не обходит серверный gate.
4. **Заказ с прямыми расчётами.** Выбрать QA-материал по1₽/м³, вручную QA-накопитель,10м³, тестовый тариф доставки0₽. Итог10₽. Оформить один новый QA-заказ, повтор нажатия не создаёт дубль. Кнопки онлайн-оплаты материалов/доставки нет; оплата водителю напрямую.
5. **Диспетчеризация.** QA-водитель на смене/свободен/с подходящей машиной и доступом получает предложение. Проверить отказ и отсутствие ответа120сек→следующий доступный. Без подписки новый offer/manual assign/accept запрещён; после окончания доступа уже назначенный рейс проходит до завершения. Эти проверки направляют уведомления: использовать согласованный QA-контур/получателей.
6. **Подписная оплата.** Выбрать явно тестовый тариф, указать QA-почту для чека, оплатить тестовым кошельком. Проверить pending→succeeded, срок/историю, повторное открытие после перезапуска приложения и продление без потери оплаченных дней. Неудачная попытка карты может оставить parentpending для другого способа — это не подтверждённый отказ всего платежа.
7. **Возврат подписки.** QA-admin→Управление подписками→свой QA-платёж. На10₽ проверить3₽partial, обязательную причину, отдельное keep/revoke/shorten только source grant. На1₽ возможен полный возврат. Для partial сумма>=1₽, остаток0или>=1₽. Коммерческие правила/тарифы требуют утверждения; тестовое решение доступа не утверждает политику.
8. **Чат.** С trial/подпиской отправить сообщение, проверить offline-черновик/retry. QA-admin: warning/mute/ban/restore, pin/rules/delete, audit. После expiry открытый чат очищается/закрывается; оплата восстанавливает доступ, сохраняя санкции. Уведомлять только QA.
9. **Контроль пути.** Anonymous→неудачный вход→успешный вход; админ видит хронологию/сохранённую историю/город, maskedcontact, auditedreveal. Проверить фильтры ошибок/незавершённости, два разных заказа, pending/late success. Для трёх ошибок одной попытки после5минут должен прийти один ownerin-app с рабочей ссылкой; получатель толькоQA-admin.
10. **Получение/отзыв.** После доставленного QA-заказа подтвердить получение и отправить1–5звёзд/текст. После перезагрузки результат сохранён, повтор не создаёт второй отзыв.

## Android и PUSH — ещё требуется физическое устройство

APK — отдельный пакет **ru.darmavoz.app.test / «Дармавоз ТЕСТ»**, testAPI/testS3/TestFirebase. Установить immutableAPK указанного codeSHA, сверить downloadSHA256, открыть и войти обычным способом в выделенный QA-профиль. Сам факт установки, реальные inset/keyboard/WebView/navigation/back/network восстановление проверить на устройстве.

Разрешить уведомления, убедиться в регистрации FCM для этого QA-устройства, отправить адресное QA-событие, проверить получение в foreground/background/после закрытия и переход в правильный заказ/чат/chronology. Повтор event_id не должен дублировать действие; logout снимает привязку устройства. Зафиксировать модель телефона/Android/version/время и фактический результат. **Сборка APK, браузерная эмуляция и no_device не доказывают эти сценарии.** У агента физического устройства/adb не было.
