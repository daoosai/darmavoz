# Подбор точек в корзине

POST /api/v1/client/orders/calculate принимает материал, машину, объём, координаты доставки, city_id и необязательный quarry_id. Подбор: app/services/order_pricing.py, публичность: pickup_points.py и relevance.py. Отсутствие действующих публичных предложений возвращает 404 «Подходящие точки не найдены.». Срок размещения/подтверждения, CRM activation и активная связь материала проверяются независимо от moderation approved.

11.10.2026 аудит «Песка лесного» на production подтвердил 20 тюменских точек с активными предложениями/ценой, но 0 публичных: 13 hidden из-за confirmation_overdue и 7 expired. Точные данные, READ ONLY скрипт и действия администратора: [отчёт](../2026-10-11-forest-sand-cart-audit.md). Код и данные не менялись.

12.10.2026: resolve_delivery_city нормализует пригород без своей доставки в ближайший настроенный рынок по координатам (100 км), применяется при создании адреса, calculate, checkout и pickup-points с lat/lon. Настроенные тарифы/прайсы сохраняют собственный city_id; SQL публичности/материала не ослабляется. Отчёт: ../2026-10-12-suburbs-cart-map.md.

Изменения 12.10.2026 развернуты только в тестовом контуре (runtime 48a4cd0a), CI success. Живой расчёт с временным пригородным city_id подтвердил тот же карьер/цену, что для Тюмени; временная запись удалена. Реальная 2ГИС на ПК/мобильном браузере подтвердила selectedAddress как центр и 0 GPS вызовов. Доказательства в отчёте suburbs-cart-map.

При переносе на production выявлены стартовые тарифы миграции Sprint 23 у пригородов без предложений. Такие копии не считаются независимым рынком: при отсутствии своего прайса выбирается ближайший операционный рынок. Изменённые/отключённые собственные тарифы сохраняют scope; неизменённая миграционная партия позволяет наследовать обновлённые цены родителя. Подробности: ../2026-10-12-suburbs-production.md.


16.10.2026 Product Owner подтвердил обязательный контракт: автоподбор только quarry;
накопители выбираются вручную через quarry_id. Расширение автоматического фильтра
отменено до коммита/deploy. Для ЮKassa на тестовом контуре цена Боя кирпича в Новом
накопителе 1 ₽/м³; городской тариф больших самосвалов 0–∞, все ставки/минимумы нулевые.
Внешний API: автоматический 404, явный накопитель 200 (1 м³ = 1 ₽, доставка 0 ₽).
Кнопка ошибки открывает MaterialBottomSheet категории/объёма, а не карту точек.
Отчёт: ../2026-10-16-cart-map-yookassa-data.md.


## 16.10.2026 — ручной выбор точки после ошибки подбора
Кнопка ошибки «Выбрать карьер/накопитель на карте» открывает PickupPointMapScreen
для материала конкретной позиции. Выбор сохраняет point_id в поле
CartItem.preferredPointId persisted Zustand корзины (frontend/src/store.ts).
CartScreen использует его как quarry_id в calculate и checkout; выбор сохраняется
при переходах и перезагрузке. Замена машины штатно сбрасывает ручную точку.
Кнопка изменения машины продолжает открывать MaterialBottomSheet.
Автоподбор API по-прежнему только quarry; backend-фильтры не менялись.

Регрессия frontend/tests/e2e/cart-pickup-fallback.spec.ts проверяет на 390/1440:
404 без точки, открытие карты, выбор накопителя, пересчёт 10 м³ × 1 ₽ = 10 ₽
при доставке 0 ₽, сохранение ID и повторный ручной расчёт после reload.
Spec включён в test deploy. Отчёт: ../2026-10-16-cart-pickup-fallback.md.
