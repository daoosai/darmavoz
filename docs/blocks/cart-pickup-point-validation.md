# Подбор точек в корзине

POST /api/v1/client/orders/calculate принимает материал, машину, объём, координаты доставки, city_id и необязательный quarry_id. Подбор: app/services/order_pricing.py, публичность: pickup_points.py и relevance.py. Отсутствие действующих публичных предложений возвращает 404 «Подходящие точки не найдены.». Срок размещения/подтверждения, CRM activation и активная связь материала проверяются независимо от moderation approved.

11.10.2026 аудит «Песка лесного» на production подтвердил 20 тюменских точек с активными предложениями/ценой, но 0 публичных: 13 hidden из-за confirmation_overdue и 7 expired. Точные данные, READ ONLY скрипт и действия администратора: [отчёт](../2026-10-11-forest-sand-cart-audit.md). Код и данные не менялись.

12.10.2026: resolve_delivery_city нормализует пригород без своей доставки в ближайший настроенный рынок по координатам (100 км), применяется при создании адреса, calculate, checkout и pickup-points с lat/lon. Настроенные тарифы/прайсы сохраняют собственный city_id; SQL публичности/материала не ослабляется. Отчёт: ../2026-10-12-suburbs-cart-map.md.
