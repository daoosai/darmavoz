# Отложенная актуализация старых тестов

Дата: 05.10.2026. Контур: develop, /opt/darmavoz_test.
Пользователь ограничил текущую задачу спринтами 24–25 и найденными при аудите
тестами подбора; остальные падения оформить отдельно.

## Что обнаружено

Диагностический запуск pytest без списка файлов собрал также scripts/manual_checks.
Он остановлен после выявления массовых старых контрактов: 81 passed, 33 failed,
KeyboardInterrupt. Это неполный прогон; полный репозиторий зелёным не объявляется.
Два падения volume из этого запуска устранены текущей задачей.

Группы, требующие отдельной актуализации и повторного воспроизведения:
- tests/test_admin_catalog.py: удаление материала с корзиной, создание/удаление
  водителя (новая обязательная категория транспорта), fixture OrderOffer без offered_at.
- tests/test_admin_email_notifications.py и дубликат scripts/manual_checks:
  monkeypatch старой функции send_admin_moderation_email, отсутствующей в driver_dispatch.
- scripts/manual_checks/test_sms.py: ожидание fallback при отказе провайдера;
  действующий код возвращает HTTP 503. Проверять согласованный контракт.
- tests/test_client_auth.py: FakeRedis без метода set.
- tests/test_client_orders.py: конфликт фиксированного номера клиента между тестами.
- tests/test_admin_equipment_update.py, tests/test_admin_quarry_update.py:
  ручное продление размещения и старые ожидания валидации.
- tests/test_avito_webhook.py::test_migrations_smoke: старое ожидание nullable.
- tests/test_dispatch_flow.py: прежние fixtures допуска и готовности маршрута;
  заявки попадают в requires_clarification вместо поиска, ручной отказ теперь 409.
- tests/test_driver_profiles_sprint11.py: OTP-регистрация возвращает 202,
  прежние ожидания немедленного создания/логина; конфликт телефонов между тестами;
  устаревшие правила модерации/статусов.

Это список наблюдённых падений, а не доказательство дефектов приложения.
Нельзя механически менять ожидаемые статусы без проверки действующей бизнес-логики.
Предлагается отдельная задача: изолировать данные тестов, отделить ручные скрипты
от автоколлекции, актуализировать API-контракты и выполнить полный pytest.

## Ограничение текущей задачи

Вышеперечисленные старые тесты не изменялись и не исключались из коллекции pytest.
Ни skip/xfail, ни отключение проверок для достижения зелёного результата не добавлены.
