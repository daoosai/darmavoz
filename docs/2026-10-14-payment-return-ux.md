# Результат оплаты: согласованный статус и авто-переход — 14.10.2026

Контур: develop / test.darmavoz.ru. Production, .env и версии не меняются.

Причина: PaymentReturn всегда показывал «Проверяем оплату заказа», а
независимая OrderPaymentsPanel уже могла показывать «Оплачено». Автоматического
перехода к заказу не было; polling панели выполнялся раз в 15 секунд.

Реализовано:
- succeeded: зелёная CheckCircle, заголовок «Оплата прошла успешно!»,
  пояснение о переходе и таймер 2,5 секунды к /client/orders/{orderId}.
- pending/waiting_for_capture: спиннер, ожидание подтверждения банка,
  последовательный GET polling каждые 2,5 секунды до финального статуса.
- Остановка опроса после terminal state; очистка таймеров/abort при закрытии.
  Временная ошибка повторяется, не выдавая её за отказ платежа.
- Ручной возврат доступен; native callback/deeplink сохранён.
- Экран обращается к защищённому API и не доверяет статусу из URL.
  Без клиентской авторизации автоматического перехода нет.
- Госномер удалён из клиентской карточки по пожеланию пользователя;
  имя и марка машины сохранены.

Backend и платёжный бизнес-цикл не менялись. Авто-переход — штатная клиентская
навигация App, без перезагрузки страницы. Данные оплаты согласуются со store.
Проверки, коммит и фактическое развёртывание будут зафиксированы после CI.
