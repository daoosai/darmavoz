
## Система проверки обновлений (UpdateService)
В мобильном приложении реализована логика проверки актуальности версии при запуске. 

**Флоу работы:**
1. На этапе `initState` главного экрана (`HomeScreen`) вызывается `UpdateService(_apiService).checkForUpdates(context)`.
2. Сервис отправляет запрос к `/api/v1/app-version` и получает `latest_version` и `download_url`.
3. С помощью пакета `package_info_plus` определяется текущая версия запущенного приложения.
4. Версии разбиваются на мажорную, минорную и патч-части (SemVer) и сравниваются.
5. Если версия бэкенда выше текущей, на экран выводится `AlertDialog` с текстом: *"Вышла новая версия приложения: 1.0.1. Пожалуйста, обновитесь для стабильной работы"*.
6. При нажатии на кнопку **"Скачать"** срабатывает пакет `url_launcher`, который переводит пользователя во внешний браузер устройства по переданной ссылке `download_url` для скачивания свежего APK (или перехода в стор).
7. Если флаг `force_update` равен `true`, модальное окно невозможно закрыть (блокирующее обновление). Если `false`, присутствует кнопка "Позже".

## 10. Сборки приложений (Flavors/Entry Points)
Для покрытия требований Sprint 9 в мобильном приложении "Дармавоз" настроена поддержка нескольких контуров из одной кодовой базы.

Вместо одного файла `main.dart` используются разделенные точки входа (Entry Points):
- `lib/main_client.dart` — запускает приложение для клиентов. Основной цвет интерфейса — глубокий синий.
- `lib/main_driver.dart` — запускает приложение для водителей. Основной цвет интерфейса — темно-зеленый (для четкого визуального разделения контуров).

### Базовые роуты водительского приложения:
- `/driver/home` — Главный экран водителя со статусом ("Свободен/Занят").
- `/driver/orders` — Экран доступных заявок (лента заказов).
- `/driver/profile` — Профиль водителя.

Навигация для водительского контура изолирована в файле `driver_router.dart` (аналогично клиентскому `app_router.dart`), который использует `StatefulShellRoute` для сохранения состояния вкладок.

Для удобного запуска в IDE (VS Code) настроен файл `.vscode/launch.json` с двумя конфигурациями: "Run Client App" и "Run Driver App".
