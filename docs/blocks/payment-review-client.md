# Клиент для модерации ЮKassa

Номер +79999999999 (нормализация 79999999999, 89999999999, 9999999999 и формат с пробелами/скобками) — единственное клиентское production-исключение для OTP 0000. app/api/client_auth.py проверяет точное совпадение нормализованного номера. send-code/register для него не вызывают SMS-сервис/провайдера; verify-code принимает только 0000, в том числе без предварительного challenge и при повторном входе. При первом входе стандартная логика создаёт Client, JWT имеет role=client и client_id. Остальные production-номера проверяются штатным validate_sms_otp, где 0000 отклоняется при USE_REAL_SMS=true.

По уточнению владельца тестовый контур сохраняет sandbox (USE_REAL_SMS=false, 0000 для обычных номеров). Общий SMS-сервис и .env не меняются. Google Play reviewer 7777 сохраняется. Новый whitelist не действует в сотруднических SMS-ручках.

app/security/auth.py запрещает клиентские JWT в get_current_user: совпадение sub/телефона с User не должно давать сотруднические права. Регрессии: tests/test_payment_review_client.py. Старый FakeRedis в test_client_auth.py обновлён до общей полной реализации для существующих rate limits.

Вход: https://darmavoz.ru/app → Я Клиент → Профиль → +79999999999 → код 0000. Тест: https://test.darmavoz.ru/app. Версии frontend/native не меняются; нужен backend-деплой, выпуск мобильной версии для этого изменения не требуется. Состояние доставки: [отчёт](../2026-10-12-payment-review-client.md).
