# Клиентская карта по геолокации — 12.10.2026

## Причина
На production запрос с city_id Патрушевой (19b142d4-1a76-4b56-9998-76b4d7162b79) возвращал только серую точку АссенизаторСервис. Три активных карьера относятся к Тюмени и успешно отдавались для её city_id. Гостевой браузер также хранит selected-city. Получение геолокации не меняло область API, а начальный обзор возвращался к центру выбранного города.

## Исправление
GET /api/v1/catalog/pickup-points/global принимает lat/lon и необязательный radius_km (50 км, максимум 200). При координатах выбирает публичные точки по географическому расстоянию независимо от населённого пункта. Без координат прежняя фильтрация city_id сохранена для совместимости. Скрытые/отказанные/необработанные CRM записи исключены; серые публичные точки сохранены.
GlobalMapScreen ждёт результата геолокации, отправляет координаты без авторизации и city_id; при отказе использует центр выбранного города. Начальный обзор вмещает найденные точки и положение пользователя. Каталог, расчёт и оформление заказов не изменены. БД, .env, номера версии/сборки не изменены.

## Проверки до доставки
8 новых API тестов: соседний населённый пункт, пригород вне городского BBox, зелёная точка с ценой, серая точка, удалённая/скрытая точка, радиус, несовместимые координаты; 35 существующих API тестов Sprint 22/24/25 прошли. npm run lint и npm run build прошли. flake8 (E9,F63,F7,F82,F401) прошёл. Три Playwright сценария с сохранённым пригородом прошли: гостевой ПК, телефон, отказ в геолокации. Реальные браузерные проверки после доставки фиксируются ниже.

## Доставка
Порядок: develop → тестовый контур → реальные API/браузер → точечный cherry-pick в main → production → реальные API/браузер. Статус на момент первого коммита: проверки до доставки; результаты доставки будут дополнены.
